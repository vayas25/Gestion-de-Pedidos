## Descripción
### Escenario
Describa de manera clara y resumida el **escenario seleccionado por el grupo**, explicando la situación planteada.
\[El tema principal del proyecto es la gestión de pedidos de una cafetería durante un turno de atención, cuenta con un registro inicial de 18 productos que se encuentran disponibles y 30 unidades que están asociadas a los pedidos, con las instrucciones aritméticas en ensamblador MIPS se calculara los valores intermedios de cantidades procesadas, diferencias y acumulaciones, se reusara registros para ver como es que surgen dependencias entre instrucciones consecutivas. Por ultimo el programa inspecciona si el calculo final es diferente de 0 para dar el código 202 o 0, este resultado será guardado en la variable estado en memoria.\]
